# Methodology

## 1. Research Objective

The goal of this project is to build a machine-learning surrogate for an
agent-based construction safety simulation and deploy the resulting model
through a reproducible MLOps pipeline.

The project investigates the following question:

> To what extent can a supervised machine-learning model reproduce worker
> safety decisions generated by a stochastic agent-based behavioral model?

The objective is not only to maximize predictive performance.

The project also focuses on:

- reproducible synthetic-data generation
- leakage-safe evaluation
- comparison of multiple model families
- experiment tracking
- decision-threshold optimization
- analysis of stochastic predictability limits
- production inference through a REST API
- automated testing and deployment

---

## 2. Source Simulation

The training dataset is generated from the companion project:

**Agent-Based Construction Safety Simulation**

https://github.com/Hickmanda/abm-construction-safety

The source model simulates construction workers whose safety behavior is
influenced by psychological and decision-making variables.

The simulation combines:

- agent-based modeling
- worker behavioral state variables
- social influence
- safety knowledge
- situational awareness
- perceived behavioral control
- behavioral intention
- Cumulative Prospect Theory parameters
- stochastic behavioral decisions

Because behavior is probabilistic, identical or similar worker states do
not necessarily produce identical labels.

This stochasticity becomes important when interpreting the achievable
machine-learning performance.
