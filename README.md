An end-to-end MLOps project for predicting construction worker safety
behavior from data generated by an agent-based simulation.

The project connects simulation, machine learning, experiment tracking,
model evaluation, REST API serving, containerization, CI/CD, monitoring,
and a public web interface into one reproducible production pipeline.

## Key Results

The final dataset contains **1,000,000 worker-decision records**
generated from 100 independent stochastic construction-safety
simulations.

Three supervised models were compared using a simulation-level split:

| Model | Validation Macro F1 |
|---|---:|
| Logistic Regression | 0.6074 |
| Random Forest | 0.6114 |
| **XGBoost** | **0.6126** |

XGBoost was selected using validation data only.

### Held-out test performance

| Metric | Value |
|---|---:|
| Accuracy | 0.7578 |
| Balanced Accuracy | 0.6177 |
| Macro F1 | 0.6259 |
| Safe F1 | 0.8480 |
| Unsafe F1 | 0.4037 |
| ROC-AUC | 0.7235 |

The production decision threshold was optimized on the validation
simulations:

```text
P(safe) >= 0.640 -> SAFE
P(safe) <  0.640 -> UNSAFE


## Project Overview

Construction safety behavior is influenced by multiple interacting
psychological, social, and decision-making factors.

Instead of starting from a conventional static tabular dataset, this
project generates training data from an existing agent-based model of
construction worker safety behavior.

The pipeline contains four major stages:

1. Run multiple independent agent-based simulations.
2. Convert worker decisions into a machine-learning dataset.
3. Train and compare multiple classification models.
4. Deploy the selected model as a production REST API and web application.

The resulting machine-learning model acts as a **surrogate model** of the
original stochastic simulation.
